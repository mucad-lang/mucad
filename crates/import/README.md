# µcad import API

[![Crates.io](https://img.shields.io/crates/v/mucad-import.svg)](https://crates.io/crates/mucad-import)
[![Documentation](https://docs.rs/mucad-import/badge.svg)](https://docs.rs/mucad-import/)

This crate provides the µcad import Rust API which is used to import arbitrary file formats into mucad.
Currently, only `toml` is implemented.
TOML files can be loaded to import data as `Tuple`.
