# µcad Language Server Protocol implementation

[![Crates.io](https://img.shields.io/crates/v/mucad-lsp.svg)](https://crates.io/crates/mucad-lsp)
[![Documentation](https://docs.rs/mucad-lsp/badge.svg)](https://docs.rs/mucad-lsp/)

The crate implements the [Language Server Protocol](https://microsoft.github.io/language-server-protocol/) for the µcad language.
It also provides the `mucad-lsp` as binary for the µcad language server.
