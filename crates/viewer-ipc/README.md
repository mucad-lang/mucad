# µcad Viewer Interprocess communication interface

[![Crates.io](https://img.shields.io/crates/v/mucad-viewer-ipc.svg)](https://crates.io/crates/mucad-viewer-ipc)
[![Documentation](https://docs.rs/mucad-viewer-ipc/badge.svg)](https://docs.rs/mucad-viewer-ipc/)

This crate provides an API to interact with the µcad viewer as a separate process.

It is within the [mucad-lsp](https://crates.io/crates/mucad-lsp) crate to control the viewer via commands.

To test it manually, run:

```sh
cargo run --bin mucad-viewer-ipc-manual-test
```
