# µcad Syntax

[![Crates.io](https://img.shields.io/crates/v/mucad-lang-parse.svg)](https://crates.io/crates/mucad-lang-parse)
[![Documentation](https://docs.rs/mucad-lang-parse/badge.svg)](https://docs.rs/mucad-lang-parse/)

This crate provides a lexer and a parser for the µcad language.
The parsing process will only operate on a single file and will result in an AST.
