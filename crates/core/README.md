# µcad core crate

[![Crates.io](https://img.shields.io/crates/v/mucad-core.svg)](https://crates.io/crates/mucad-core)
[![Documentation](https://docs.rs/mucad-core/badge.svg)](https://docs.rs/mucad-core/)

This crate provides the core functionality of µcad.
It provides the basic data structures used to handle geometries and operations on them.
